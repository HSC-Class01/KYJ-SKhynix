# SK hynix DART Financial Intelligence

[![대시보드 바로가기](https://img.shields.io/badge/SK%20hynix-대시보드%20바로가기-1E4D2B?style=for-the-badge)](https://hsc-class01.github.io/KYJ-SKhynix/)

SK하이닉스(주식코드 `000660`)의 DART 공시 재무 데이터를 분석하는 것을 목표로 하는 저장소입니다.

> **현재 저장소 상태:** README의 회사명을 SK하이닉스로 수정했지만, 나머지 구현은 아직 롯데지주 기준입니다. `index.html`, `update_dart.py`, `update-dart.yml`에서 롯데 관련 문구와 주식코드 `004990`을 확인했습니다. 따라서 이 저장소의 현재 대시보드와 데이터 수집 결과를 SK하이닉스 재무정보로 간주하면 안 됩니다. SK하이닉스 데이터로 사용하려면 대시보드, 수집 코드, 워크플로의 회사 정보와 종목코드를 함께 전환해야 합니다.

## 현재 구현에서 확인된 기능

- DART 사업보고서(11011), 반기보고서(11012), 1분기보고서(11013), 3분기보고서(11014) 데이터 수집 코드
- 연결재무제표(CFS)를 우선 사용하고, 연결 데이터가 없으면 별도재무제표(OFS) 사용
- 매출액, 영업이익, 당기순이익, 자산, 부채, 자본, 현금흐름 등 주요 수치와 재무비율 계산
- 연간·반기·분기 표와 시각화용 대시보드
- GitHub Actions 월간 예약 실행 및 수동 실행 설정

위 기능의 현재 기업 설정은 SK하이닉스가 아닌 롯데지주입니다.

## DART API 키

데이터 수집에는 OpenDART 인증키가 필요합니다. 실제 전환 후에는 GitHub Actions Secrets에 `DART_API_KEY` 이름으로 등록해야 합니다. 키를 Python 파일이나 README에 직접 입력하지 마세요.

## 저장소 파일

- `index.html`: GitHub Pages 대시보드 (현재 롯데지주 기준)
- `update_dart.py`: DART 데이터 수집 및 지표 계산 코드 (현재 기본 종목코드 `004990`)
- `update-dart.yml`: DART 데이터 업데이트 및 Pages 배포 워크플로 설정 (현재 롯데 관련 이름과 경로 포함)
- `GITHUB_SETUP.txt`: 기존 롯데 저장소 이름을 참조하는 배포 안내

## SK하이닉스 전환 시 확인할 항목

1. 수집 코드의 기본 종목코드를 SK하이닉스 `000660`으로 변경합니다.
2. 데이터 메타 정보와 대시보드의 회사명, 색상, 링크를 SK하이닉스 기준으로 변경합니다.
3. 워크플로의 스크립트 경로와 실행 이름을 실제 저장소 구조에 맞춥니다.
4. 국내 peer firms와 설명 문구를 반도체 업종 기준으로 검토합니다.
5. 변환 후 Actions를 실행해 수집된 회사와 종목코드를 확인하고 Pages 배포를 확인합니다.

## 지표 정의

- 유동비율 = 유동자산 / 유동부채 × 100
- 부채비율 = 부채총계 / 자본총계 × 100
- 영업이익률 = 영업이익 / 매출액 × 100
- 순이익률 = 당기순이익 / 매출액 × 100
- ROA = 당기순이익 / 총자산 × 100
- ROE = 당기순이익 / 자본총계 × 100

재무비율은 공시 재무제표 계정과목을 기반으로 계산한 참고 지표이며, 계정과목명이 다른 보고서는 일부 항목이 누락될 수 있습니다. ROA/ROE는 평균자산·평균자본이 아니라 기말 잔액 기준입니다.
